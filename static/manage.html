Supported models and API usage

All models are served on the same port as the current EasyCLIProxyAPI core (default 8317). No extra port is needed; send standard requests directly to http://127.0.0.1:8317.

OpenAI-compatible text-to-image example:

curl -X POST "http://127.0.0.1:8317/v1/chat/completions" \
  -H "Authorization: Bearer your CPA key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gflow-nano-banana-2.1",
    "messages": [{"role": "user", "content": "a cute cyberpunk kitten"}],
    "stream": true
  }'

OpenAI-compatible text-to-video example (Veo 3.1):

curl -X POST "http://127.0.0.1:8317/v1/chat/completions" \
  -H "Authorization: Bearer your CPA key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gflow-veo-3.1-fast",
    "messages": [{"role": "user", "content": "aerial view of golden sunlight glinting on ocean waves"}],
    "stream": true
  }'

Method 1: One-click sync with browser assistant (recommended) Free extension

Browser extension GitHub source: https://github.com/daodeqing/cpa-plugin-GFlow/tree/main/browser-extension

  1. Download and load the extension: copy the download URL, open it in the browser address bar and unzip it, then in chrome://extensions/ enable "Developer mode" and click "Load unpacked".
  2. Paste config: click "Copy extension config" above, paste it into "Quick import" in the extension popup (the endpoint and credentials are filled in automatically), and enter the current Google account email.
  3. One-click sync: sign in to flow.google.com in the same browser, then click "Save and sync now" in the extension. It activates the session in the background and submits the credentials.

What is this? See the detailed description

This is a free browser assistant installed in Chrome / Edge that automatically syncs the Cookie of an already signed-in Flow session. It does not install the EasyCPA plugin again.

The embedded EasyCPA window cannot download directly; paste the URL into a browser address bar to download.

Config is stored only in the current Chrome extension; do not share management credentials.

Method 2: Paste manually
How do I get a Cookie / Session Token?
  1. Sign in to Google Flow, press F12 → Network, check Disable cache, then refresh.
  2. Click a request sent to the current Flow site, then copy the Cookie value from Headers → Request Headers and paste it above.

If you see "Provisional headers", pick a request that actually completed. Do not copy Set-Cookie. If Application → Cookies contains __Secure-next-auth.session-token, copy only its Value; otherwise use the extension.

Cookie strings, Cookie JSON, and Session Token are supported. Sync again after the sign-in expires; do not share Cookie.

Only sync accounts you are entitled to use; adding one validates the login, queries the quota and may create Projects, but never generates automatically. Flow credits and CAPTCHA fees are billed separately.
